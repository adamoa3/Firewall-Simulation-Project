This application uses Python and the scapy library to read in packets from the host device's network interface. Each packet is processed and information is displayed on the GUI written with PyQt6. The user can use the interface to set their own firewall rules, and the decision that would be made by the system is displayed for each packet. Connections are also tracked, and reverse DNS searches are performed to inform the user of where exactly the connection is coming from. The user also has the ability to reorder firewall rules, change the default amount of time a state is tracked for, and set the default policy to be enacted.
